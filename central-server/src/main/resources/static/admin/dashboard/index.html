                            참여 PC 운영 · Provider 보호

                            고품질·다중응답보다 참여 PC 보호가 우선입니다. 위험 Provider는 고급 요청에서 제외하고, 회복되면 normal로 되돌립니다.

                            보호 요약

                              알림 목록

                                실행 계획

                                  길드 ID('길드 상세'에서 입력)를 기준으로 과부하 현황을 새로고침하세요.

                                  채널 AI

                                  질문식 마법사로 채널 AI 이름·역할·말투·답변 길이·안전 규칙을 만든 뒤 저장합니다.

                                  안내

                                  ‘＋ 채널 AI 만들기’를 누르면 오른쪽에서 입력 패널이 열립니다. 만든 채널 AI 목록은 ‘길드 상세 → 채널 AI’ 카드에서 확인합니다.

                                  이 채널 AI 만들기

                                  마법사 옵션을 불러오는 중…

                                  모델 선택 정책

                                  채널마다 답변 속도, 허용 모델, 선호 모델, Provider 태그, 보호 정책을 확인하고 저장합니다. 질문 전에 실제로 선택될 모델과 fallback 이유도 봅니다.

                                  모델 후보

                                    선택 결과

                                      길드 ID와 채널 ID를 입력한 뒤 모델 후보를 확인하세요.

                                      채널 지식 관리 · RAG

                                      채널별 지식공간을 만들고 링크/텍스트/FAQ를 추가합니다. 민감정보·내부망 URL은 자동으로 검토/차단 상태가 됩니다.

                                      RAG 준비 상태

                                        색인 작업

                                          길드 ID를 입력한 뒤 RAG 상태를 새로고침하세요.

                                          품질·신고 관리

                                          답변 원문이나 프롬프트를 저장하지 않고, 요청 ID·평점·사유만 수집해 모델 선택과 채널 AI 개선 근거로 사용합니다.

                                          품질 요약

                                            신고 검토 큐

                                              모델 품질 신호

                                                길드 ID를 입력한 뒤 품질 현황을 새로고침하세요.

                                                AI 프리셋 관리

                                                서버 안 프리셋을 만들고, 웹 카탈로그에 게시하고, 다른 서버가 그대로 가져갈 수 있게 관리합니다.

                                                서버 프리셋

                                                  웹 카탈로그

                                                    신고/검수 큐

                                                      가져올 프리셋의 [미리보기]를 먼저 누르면, 덮어쓰기/승인 필요 여부를 확인한 뒤 가져올 수 있습니다.
                                                      길드 ID를 입력한 뒤 프리셋을 새로고침하세요.

                                                      고급 응답 · 다중응답/진행형

                                                      여러 Provider 후보 답변을 비교·합성하되, 과부하 위험과 민감 질문에서는 자동으로 보수적으로 동작하게 관리합니다.

                                                      다중응답 운영 상태

                                                        기능 플래그/제한

                                                          추천 fanout 미리보기

                                                            Provider 부하

                                                              최근 실행

                                                                길드 ID를 입력한 뒤 운영 상태를 새로고침하세요.

                                                                정책 설정

                                                                서버 환영 메시지·자동 승인·관리자 접근을 설정합니다. OAuth 활성 + 로그인 시에만 동작합니다.

                                                                기존 정책

                                                                관리자 접근 (토큰 방식)

                                                                OAuth를 아직 켜지 않은 환경이라면 ENV_FILE의 CENTRAL_DASHBOARD_ADMIN_TOKEN 값을 입력하세요. 이 값은 현재 브라우저 세션에만 저장됩니다.

                                                                토큰 미설정: 공개 읽기만 가능합니다.
                                                                읽기 5초 폴링 · 관리자 작업은 OAuth 또는 X-Dashboard-Admin-Token 필요 · API: /api/metrics, /api/dashboard
