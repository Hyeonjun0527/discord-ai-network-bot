                        Model routing

                        모델 라우팅은 “정책 → 후보 → 실제 선택”만 보면 됩니다

                        채널을 열면 현재 정책과 후보를 자동으로 불러옵니다. 후보에서 모델을 고르면 정책·테스트 입력이 같이 채워집니다.

                        –선택/추천 모델
                        –사용 가능 후보
                        –차단/불가 모델
                        –Provider 적합도

                        🧭 모델 라우팅 정책

                        이 채널의 질문이 어떤 모델로 라우팅될지 정합니다. 비워두면 서버 기본값을 따릅니다.

                        모델 후보

                        • ‘모델 후보 보기’를 누르면 표시됩니다.

                        선택 결과

                        • ‘선택 결과 확인’을 누르면 표시됩니다.
                        채널을 선택한 뒤 ‘현재 정책 불러오기’를 누르세요.
                        RAG pipeline

                        RAG는 “공간 → 소스 → 색인 → 검색 확인” 네 단계만 보세요

                        지식공간을 목록에서 고르면 ID가 자동으로 채워집니다. 다음 액션을 따라가면 검색 가능한 상태까지 이어집니다.

                        –지식공간
                        –색인된 소스
                        –차단/검토
                        –품질 밴드

                        지식공간 선택

                        • ‘상태 새로고침’을 누르면 공간 목록이 표시됩니다.

                        RAG 다음 액션

                        • 준비 상태를 불러오면 다음 액션이 표시됩니다.
                        지식공간

                        📚 지식공간 만들기

                        이 채널 AI가 참고할 RAG 지식공간을 만듭니다. 만든 뒤 아래에서 소스를 추가하세요.

                        지식 소스 추가

                        ➕ 소스 추가

                        링크·텍스트·FAQ 등을 지식공간에 추가합니다. 비밀번호·API 키 등 민감정보는 넣지 마세요.

                        색인 작업

                        ⚙️ 색인 작업 큐잉 · 완료

                        추가한 소스를 임베딩 색인 큐에 넣고, 외부 색인 완료/실패를 기록합니다.

                        검색 · 평가

                        🔎 검색 테스트 · RAG 평가

                        색인된 지식이 실제 질문에 잘 매칭되는지 확인합니다. 골든 케이스로 정확도(Recall@K)도 평가할 수 있습니다.

                        RAG 준비 상태

                        • ‘상태 새로고침’을 누르면 표시됩니다.

                        색인 작업

                        • 색인 작업이 여기 표시됩니다.
                        채널을 선택한 뒤 ‘상태 새로고침’을 누르세요.
                        Quality control

                        품질 관리는 “현황 → 신고 선택 → 처리”로만 흐릅니다

                        탭을 열면 신고 큐와 모델 신호를 자동으로 가져옵니다. 큐 항목의 선택 버튼을 누르면 검토 폼까지 바로 이동합니다.

                        –총 피드백
                        –검토 대기
                        –채널 품질
                        –최근 사유
                        피드백 기록

                        📝 품질 피드백 저장

                        특정 답변의 품질을 기록하거나 신고합니다. 민감정보·프롬프트 원문은 넣지 마세요(토큰/API 키 패턴은 자동 마스킹).

                        신고 검토

                        🚩 신고 검토 처리

                        신고 큐의 항목을 확인하고 처리 상태를 기록합니다.

                        품질 요약

                        • ‘품질 현황 새로고침’ 후 표시됩니다.

                        신고 검토 큐

                        • 검토할 신고가 여기 표시됩니다.

                        모델 품질 신호

                        • 모델별 품질 지표가 여기 표시됩니다.
                        채널을 선택한 뒤 ‘품질 현황 새로고침’을 누르세요.
                        Advanced responses

                        다중응답은 “안전 여부 → fanout → 최근 실행”만 먼저 보세요

                        운영 상태를 자동 로딩해 고급 모드를 켜도 되는지 먼저 보여줍니다. 필요할 때만 정책 폼을 펼치면 됩니다.

                        –최근 실행
                        –Provider 부하
                        –보호 차단
                        –채택률
                        다중응답 정책

                        🧠 다중응답(여러 후보) 정책

                        한 질문에 여러 후보 답변을 만들어 비교/합성할지 설정합니다. 후보 수가 많을수록 참여 PC 부하가 커집니다.
