남는 컴퓨팅으로 동료들의 /ask 질문에 답하세요. 디스코드에서 받은 토큰 하나면 됩니다. 채널 AI 프리셋은 웹에서 찾아보고, 설치는 OS별 복붙 명령으로 시작합니다. 금전 거래 없음 — 기여와 공정성.

설치 명령 보기 ↓ 채널 AI 프리셋 보기 // 먼저 디스코드에서 /provider-join → 토큰 받기
STEP 01

토큰 받기

디스코드에서 /provider-join → 내 OS 선택 → 10분·1회용 토큰 발급.

STEP 02

터미널 열기

아래 OS 탭에서 단축키/GUI 방법대로 터미널 또는 PowerShell을 먼저 여세요.

STEP 03

연결 확인

실행되면 디스코드 /provider-status 로 온라인 상태 확인.

// 설치 — 내 컴퓨터를 고르세요
터미널 여는 법
단축키: ⌘ Space → Terminal 입력 → Enter
GUI: Finder → 응용 프로그램 → 유틸리티 → 터미널
terminal — zsh 
# 1) Ollama 설치 + 모델 (관리자 권한 불필요)
brew install ollama
brew services start ollama
ollama pull llama3.1:8b
# 2) 에이전트 + 체크섬 받기(GitHub Release)
curl -L -o discord-ai-provider-agent-macos https://github.com/Hyeonjun0527/discord-assistant/releases/latest/download/discord-ai-provider-agent-macos
curl -L -o SHA256SUMS.txt https://github.com/Hyeonjun0527/discord-assistant/releases/latest/download/SHA256SUMS.txt
# 3) 무결성 검증 — OK 가 나와야 함
shasum -a 256 -c SHA256SUMS.txt --ignore-missing
# 4) 실행 (일반 사용자 권한, sudo 불필요)
chmod +x discord-ai-provider-agent-macos
./discord-ai-provider-agent-macos --token <디스코드에서-받은-토큰> --relay-url wss://discord-ai.yeon.world/agent
i

이 도구는 일반 사용자 권한으로 실행합니다(sudo·관리자 불필요). 설정·로그는 ~/Library/Application Support / ~/.config 아래에만 저장됩니다. 위 curl 로 받으면 격리(quarantine) 속성이 붙지 않아 Gatekeeper 경고 없이 실행됩니다(brew 설치도 동일). 신뢰의 근거는 위 3) 무결성 검증(OK 확인)과 빌드 attestation 입니다. (GUI 앱이 아니라 터미널에서 실행하는 도구라 더블클릭하지 않습니다.)

PowerShell 여는 법 (관리자 권한 불필요)
단축키: Win + X → 터미널 또는 Windows PowerShell
GUI: 시작 버튼 → PowerShell 검색 → 그냥 클릭해서 열기
PowerShell 
# 1) Ollama 설치 + 모델 (관리자 권한 불필요)
winget install --id Ollama.Ollama -e --accept-source-agreements
ollama pull llama3.1:8b
# 2) 에이전트 + 체크섬 받기(GitHub Release)
Invoke-WebRequest https://github.com/Hyeonjun0527/discord-assistant/releases/latest/download/discord-ai-provider-agent-windows.exe -OutFile discord-ai-provider-agent-windows.exe
Invoke-WebRequest https://github.com/Hyeonjun0527/discord-assistant/releases/latest/download/SHA256SUMS.txt -OutFile SHA256SUMS.txt
# 3) 무결성 검증 — 출력 해시가 SHA256SUMS.txt 의 windows 줄과 같아야 함
Get-FileHash discord-ai-provider-agent-windows.exe -Algorithm SHA256
type SHA256SUMS.txt
# 4) 실행 (일반 사용자 권한)
.\discord-ai-provider-agent-windows.exe --token <디스코드에서-받은-토큰> --relay-url wss://discord-ai.yeon.world/agent
i

이 도구는 일반 사용자 권한으로 실행합니다(관리자 PowerShell 불필요). 설정·로그는 %APPDATA% 아래에만 저장됩니다. 신뢰의 근거는 위 3) 무결성 검증(해시 일치)과 빌드 attestation 입니다. SmartScreen 경고가 보이더라도 우회하지 말고 해시를 확인하세요(다르면 실행 금지). 더 매끄럽게 받으려면 winget install Hyeonjun0527.DiscordAiProviderAgent 또는 Scoop 으로 설치하면 해시가 자동 검증됩니다.

터미널 여는 법
단축키: Ctrl + Alt + T
GUI: 앱 메뉴/프로그램 목록에서 Terminal 또는 터미널 검색

curl -L -o SHA256SUMS.txt https://github.com/Hyeonjun0527/discord-assistant/releases/latest/download/SHA256SUMS.txt
# 3) 무결성 검증 — OK 가 나와야 함
sha256sum -c SHA256SUMS.txt --ignore-missing
# 4) 실행 (일반 사용자 권한, sudo 불필요)
chmod +x discord-ai-provider-agent-linux
./discord-ai-provider-agent-linux --token <디스코드에서-받은-토큰> --relay-url wss://discord-ai.yeon.world/agent
i

일반 사용자 권한으로 실행합니다(sudo 불필요). 설정·로그는 ~/.config 아래에만 저장됩니다. 상시 구동은 사용자 단위 systemctl --user 서비스로 등록하세요(소스의 packaging/ 가이드, 시스템 서비스 등록 불필요).

// 안전하게 설치하기 — 설치 전 확인
검증

출처·해시 확인

반드시 GitHub Release에서 받고, SHA256SUMS.txt 로 해시를 검증하세요. GitHub artifact attestation과 SBOM으로 빌드 출처를 확인할 수 있습니다. brew·winget·scoop 로 설치하면 해시가 자동 검증됩니다.

권한

관리자 권한 불필요

에이전트는 일반 사용자 권한으로 동작합니다. sudo·관리자 PowerShell·시스템 폴더 쓰기·방화벽/레지스트리 변경이 필요 없습니다. 설정·로그는 홈 디렉터리에만 저장됩니다.

기본값

안전한 기본 설정

하루 처리 한도 15건·동시 1건이 기본이며, 무제한은 --allow-unlimited 로만 가능합니다. Ollama 는 기본 localhost 전용입니다.

!

개인정보 주의 — /ask 로 들어온 다른 사용자의 질문 내용이 당신(프로바이더)의 PC로 전송되어 로컬 AI가 처리합니다. 반대로 당신이 디스코드에서 질문하면 그 내용이 다른 사용자의 PC로 전송될 수 있습니다. 비밀번호·API 키·토큰·주민번호 등 민감정보나 개인정보는 절대 입력하지 마세요. 에이전트는 프롬프트 원문을 로그/파일에 저장하지 않습니다.
