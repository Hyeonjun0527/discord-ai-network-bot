개인정보 주의

            
/질문 으로 들어온 다른 사용자의 질문이 당신의 PC로 전송되어 로컬 AI가 처리하고, 반대로 당신의 질문도 다른 사용자의 PC로 전송될 수 있습니다. 비밀번호·API 키·토큰·개인정보는 절대 입력하지 마세요. 에이전트는 프롬프트 원문을 로그/파일에 저장하지 않습니다.
