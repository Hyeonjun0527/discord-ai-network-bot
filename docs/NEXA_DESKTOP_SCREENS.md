# NEXA Provider Agent — 데스크톱 앱 화면정의 (ASCII)

> 데스크톱 Provider Agent 앱의 전체 화면 와이어프레임 정의.
> 모든 화면은 **같은 뼈대**를 공유한다. 정렬보다 **구조 전달**을 우선해서 본다.
> (한글은 모노폰트에서 2칸을 먹어 오른쪽 테두리가 약간 들쭉날쭉할 수 있음)

---

## 디자인 시스템 (공통 규칙)

- **상단바**: `● ● ●` + `◆ NEXA Provider Agent` + 우측 버전(`v0.31.0`)
- **좌측 사이드바**: 로고 → 상태뱃지(`● AI 제공 중`) → 6개 전역 탭
  - 활성 탭은 **왼쪽 `┃` 액센트**로만 표시 (빈 원 ❌)
- **상태 점 언어 통일**
  - `●` 켜짐 / 정상 / 제공 중
  - `○` 꺼짐 / 미사용
  - `⏸` 일시중지
  - `⚠` 승인 대기 / 오류
- **콘텐츠는 카드 기반**
- **위험 작업(`제거` 등)은 절대 즉시 버튼 ❌** → `⋯` 메뉴 + 확인 모달
- **서버 내부 화면(07~13)**: `서버` 탭 활성 상태에서 상단에 **서버 상세 서브탭**이 깔림

### 화면 구성

| 구분 | 화면 |
|------|------|
| 전역 탭 (6) | 01 홈 · 02 모델 · 03 로컬 실행 · 04 서버 · 05 로그 · 06 설정 |

## 설계 포인트

- **개요(07) ↔ Provider(13) 역할 분리**
  - 개요 = "**내** 제공 상태 + 정책" 요약
  - Provider = "**참여자 전원** 관리"
  - 이렇게 나눠야 개요 화면이 터지지 않음
- **참여자별 컨트롤** — `범위`(scope·대줄 수 있는 모델 제한), `한도`(하루 처리량), `재개/일시중지`, `제거`
  - 슬래시 명령 `/provider-limit · /provider-scope · /provider-pause`를 GUI로 흡수
- **상태 점 언어 유지** — `●` 제공 중 / `⏸` 일시중지 / `⚠` 승인 대기, 나(이 PC)에는 `기본` 배지
- **위험 작업은 전부 `⋯` + 모달 뒤로** — 실수로 즉시 삭제되는 경로 없음
