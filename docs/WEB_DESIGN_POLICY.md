# WEB_DESIGN_POLICY — 설치 랜딩(`/install`) 디자인 정책

대상: `central-server/src/main/resources/static/install.html` (봇 추가 랜딩 + 프로바이더 설치).

이 문서는 랜딩의 **디자인 언어·테마 토큰·그레인 정책**을 고정하고, 현재 **미해결 이슈(디스플레이별 밴딩)** 와 그 **제거 계획**을 남긴다. 색/테마 변경은 반드시 아래 토큰 규칙을 따른다(하드코딩 금지).

## 1. 디자인 언어

- **다크 사이버 네온 + 글래스모피즘 + 풀페이지 시네마틱 스크롤**(iron-man 식 pinned scroll). 긴 섹션(`#cine`) + `sticky` 스테이지 + 스크롤 진행도(0~1) 매핑.
- 히어로 비주얼: **Three.js 네온 글래스 설치 패널**(두꺼운 투명 아크릴 프레임 + 멀티컬러 RGB 네온 림: 시안·블루·바이올렛·퍼플·핑크). 스크롤로 회전/줌 스크럽, 비트(STEP) 텍스트 전환, `SEQ`/진행 바/HUD.
- 질감: **그레이니 그라데이션(grainy gradient / film grain)** 을 *의도된 미감*으로 채택. 노이즈 오버레이가 프리미엄 다크 UI 트렌드와 맞고, 동시에 그라데이션 디더 역할도 한다.
- 폴백: `prefers-reduced-motion`·WebGL 미지원·CDN 실패 시 정적 webp(`/img/install-panel.webp`) + 비트 텍스트 유지.

## 2. 테마 토큰 (단일 진실원천)

모든 **브랜드/네온 색**은 `install.html` 의 `:root` 토큰을 경유한다. **새 색을 hex 로 하드코딩하지 않는다**(필요하면 토큰 + `color-mix()` 로 농도 조절).

- 팔레트: `--c-cyan` `--c-blue` `--c-violet` `--c-purple` `--c-pink`
- 강조: `--c-accent`(메인, 현재 violet) · `--c-accent2`(보조)
- 파생 그라데이션: `--grad-cta` `--grad-accent` `--grad-neon`
- **테마 교체**: `--c-accent` 한 줄(또는 팔레트 5색)만 바꾸면 **CSS 와 WebGL 패널이 동시에** 따라온다.
- **구조색은 테마 무관 고정**: `--bg-0/1`, `--panel`, `--line`(중립 블루그레이). accent 로 물들이지 않는다.
- **WebGL(Three.js) 도 동일 토큰**: `getComputedStyle(:root)` 로 토큰을 읽어 림/조명/카드/로고에 적용(JS 에 브랜드 hex 하드코딩 금지, 폴백 기본값만 허용).

## 3. 그레인(film grain) 오버레이

- `.cine-noise`: 시네마틱 스테이지에서 **캔버스 위**(z-index 3, HUD·텍스트 아래)에 그레이스케일 노이즈, `mix-blend-mode: overlay`. WebGL 네온 글로우 위에 얹혀 디더 + 미감.
- `body` 배경 최상단에도 노이즈 레이어(정적 섹션용).
- 조절 파라미터: 오버레이 `opacity`(강도), SVG `baseFrequency`(입자 크기). 움직이는 필름 그레인으로 확장 시 `prefers-reduced-motion` 에서 정지.

## 4. ⚠️ 미해결 이슈 — 디스플레이별 라디얼 글로우 밴딩

- **증상**: 동일 코드인데 **MacBook Pro(광색역 P3 / EDR) 디스플레이에서 라디얼 글로우·네온이 계단(밴딩)** 으로 보이고, 일부 외장 모니터(LG 등)에서는 자연스럽게 보인다. 모니터가 8비트 양자화 단차를 드러내느냐의 차이.
- **현 상태**: 그레인 디더로 **완화를 시도했으나 근본 해결되지 않음**. 그레인 미감으로 시각적으로 덮였을 뿐, 밴딩 자체는 잔존한다. → *"밴딩 디더만으로 해결될 문제가 아니다"* 로 결론.
- **추정 원인(복합)**: 8bit 프레임버퍼/그라데이션 양자화 + macOS EDR 톤매핑 + 라디얼 글로우의 비교적 하드한 `transparent N%` 스톱 + sRGB→P3 색관리.

## 5. 밴딩 제거 계획 (우선순위 — 그레인 미감은 유지)

1. **그라데이션 스톱 소프트닝**(가장 싸고 효과 큼·모니터 독립): `transparent 60%` 같은 단일 하드 스톱을 **다단계 이징 스톱**으로 바꿔 단차 진폭을 잘게 쪼갠다. body 라디얼 + `.cine-vignette` + WebGL 헤일로/림 모두 대상.
2. **글로우 진폭 축소**: 글로우 alpha/대비를 낮추고 spread 를 넓혀 인지 단차 자체를 줄인다.
3. **WebGL 글로우 자체 디더**: 림/헤일로 `CanvasTexture` 에 노이즈를 *베이크*(프레임버퍼 양자화 전 단계에서 디더)하거나 프래그먼트에 미세 디더 추가.
4. **(실험) 고정밀/HDR 캔버스**: `WebGLRenderer` 색공간/`display-p3`·float 프레임버퍼 지원·성능 검토.
5. **검증 체계**: 밴딩은 헤드리스(SwiftShader)로 **재현 불가** → 반드시 실제 MacBook Chrome 에서 확인. 전/후 비교 캡처는 `docs/audits/` 에 남긴다.

> 제약: 위 작업은 **그레이니 미감을 유지하면서 밴딩만 제거**하는 방향으로 한다(둘 다 만족). 1번부터 적용하고 MacBook 실기기로 검증한다.
