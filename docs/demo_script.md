## 사전 준비 체크리스트

발표 전 반드시 확인:

- [ ] Discord 테스트 서버 접속 완료
- [ ] 봇이 서버에 초대되어 있고 온라인 상태 확인 (`python -m discord_assistant`)
- [ ] `#demo-채널`에 샘플 메시지 20개 이상 사전 입력 완료
- [ ] 모델 설정: `/settings` → `claude-sonnet-4-6` 또는 `gpt-4o-mini` (한국어 데모용)
- [ ] 화면 공유 또는 프로젝터 연결 확인
- [ ] Ollama 실행 확인 (`ollama serve`)

## Scene 1 — 문제 제기 (1분)

**[0:00 ~ 1:00]**

> (화면: Discord의 `#일반` 채널 — 메시지가 많이 쌓인 화면)

---

안녕하세요. 저는 Discord AI Assistant를 주제로 졸업 프로젝트를 진행한 [이름]입니다.

Discord를 사용하다 보면 이런 경험, 한 번쯤 있으시죠?

잠깐 자리를 비운 사이에 채널에 메시지가 수십, 수백 개 쌓여있는 상황.  
"무슨 얘기 했지?" 하고 스크롤을 한참 올려가야 하거나, 결국 중요한 결정 사항을 놓치는 경우.

특히 여러 Discord 서버를 동시에 관리하거나, 스터디·팀 프로젝트·커뮤니티 서버를 운영할 때  
이 **"대화 맥락 파악 비용"**은 매우 높습니다.

저는 이 문제를 AI로 해결하고자 했습니다.  
"Discord 채널 대화를 AI가 자동으로 요약하고, 원하는 것을 물어볼 수 있다면 어떨까?"

그렇게 만든 것이 바로 **Discord AI Assistant**입니다.

## Scene 2 — 핵심 기능 라이브 데모 (2분)

**[1:00 ~ 3:00]**

> (화면: `#demo-채널` 으로 이동. 사전 입력한 스터디 관련 대화가 보이는 상태)

---

지금 화면에 보이시는 것처럼, 스터디 모임 일정을 잡는 대화가 약 20개 정도 있습니다.  
여기서 바로 AI 명령을 실행해보겠습니다.

---

### 2-1. `/summarize` 실행

> (Discord에서 입력: `/summarize limit:20`)

**[1:10]** `/summarize limit:20` 을 실행합니다.

봇이 채널의 최근 20개 메시지를 수집하여 분석 중입니다...  
잠시 기다리시면, 결과가 나옵니다.

> (봇 응답 대기 — 약 2~5초)

보시는 것처럼 AI가 자동으로 다음을 추출했습니다:

- **주요 주제**: 파이썬 머신러닝 스터디 일정 논의
- **결정 사항**: 다음 주 토요일 오후 4시, 카페 스터디룸, 저녁 식사 포함
- **액션 아이템**: 박지훈 — 스터디 자료 및 저녁 식사 예약 담당; 참석자 전원 — 노트북·파이썬 환경 사전 설치

스크롤을 전혀 하지 않고, 단 몇 초 만에 핵심 내용을 파악할 수 있습니다.

---

### 2-2. `/ask` 실행

> (Discord에서 입력: `/ask question:스터디 시간이 언제로 결정됐어?`)

**[2:00]** 이번에는 채널 내용을 바탕으로 질문을 해보겠습니다.

"스터디 시간이 언제로 결정됐어?" 라고 물어봅니다.

> (봇 응답 대기 — 약 2~3초)

AI가 채널 대화를 분석해서 "다음 주 토요일 오후 4시, 카페 스터디룸"이라고 정확히 답해주네요.  
단순 검색이 아니라, 대화의 흐름을 이해하고 결론을 추출합니다.

---

### 2-3. `/chat` 실행

> (Discord에서 입력: `/chat message:파이썬 머신러닝 스터디 준비물 리스트 만들어줘`)

**[2:40]** 마지막으로 채널 맥락 없이 AI에게 직접 질문하는 `/chat` 기능입니다.

"파이썬 머신러닝 스터디 준비물 리스트 만들어줘" 라고 요청해봅니다.

> (봇 응답 대기)

이처럼 채널과 관계없이 AI 어시스턴트로 자유롭게 활용할 수 있습니다.

## Scene 3 — Settings 데모 (1분)

**[3:00 ~ 4:00]**

> (Discord에서 입력: `/settings`)

---

이 봇의 특징 중 하나는 여러 AI 제공자를 즉시 전환할 수 있다는 점입니다.

`/settings` 명령을 실행하면 인터랙티브 설정 패널이 열립니다.

> (봇 응답: 설정 패널 Embed + 버튼들이 나타남)

보시는 것처럼 버튼만 클릭하면 됩니다:

- **Ollama (로컬)**: 인터넷 없이 로컬에서 실행. 데이터가 외부로 나가지 않습니다.
- **OpenAI**: GPT-4o 계열 모델. 고품질, 빠른 응답.
- **Anthropic**: Claude 계열 모델. 탁월한 한국어 품질.

> (버튼 클릭: "Anthropic" 선택)

**[3:30]** 지금 Anthropic으로 전환해보겠습니다.  
바로 모델 선택 화면이 나오고, `claude-sonnet-4-6`을 선택합니다.

> (모델 선택 후 확인 메시지)

이제 모든 AI 명령이 Claude를 통해 처리됩니다.  
API 키도 이 패널에서 직접 설정할 수 있으며, 암호화되어 저장됩니다.

## Scene 4 — 기술 아키텍처 개요 (1분)

**[4:00 ~ 5:00]**

> (화면: `docs/ARCHITECTURE.md` 또는 슬라이드의 아키텍처 다이어그램으로 전환)

---

마지막으로 기술 구조를 간략히 설명드리겠습니다.

Discord 사용자가 슬래시 명령을 입력하면, `discord.py` 기반의 봇 서버가 이를 수신합니다.  
봇은 SQLite 데이터베이스에서 서버 설정을 불러오고,  
설정에 따라 **Ollama 로컬 서버**, **OpenAI API**, 또는 **Anthropic API** 중 하나로 요청을 보냅니다.

AI 응답이 돌아오면 Discord Embed 형태로 포맷팅되어 사용자에게 전달됩니다.

주요 기술 스택:
- **Backend**: Python 3.11, discord.py 2.7.1, aiosqlite
- **암호화**: Fernet 대칭키 암호화 (API 키 보호)
- **AI 제공자**: Ollama, OpenAI, Anthropic
- **대시보드**: FastAPI + Next.js (선택 사항)

이 프로젝트는 로컬 모델부터 최신 클라우드 API까지 하나의 인터페이스에서 통합 관리할 수 있는  
실용적인 Discord AI 어시스턴트입니다.

이상으로 발표를 마치겠습니다. 질문 있으시면 말씀해 주세요. 감사합니다.

## 예상 Q&A

**Q: 로컬 모델과 클라우드 모델의 품질 차이가 얼마나 나나요?**  
A: 한국어 기준으로 클라우드 모델(Claude Sonnet, GPT-4o)이 확연히 우수합니다. 로컬 모델 중에서는 llama3.2:11b가 가장 좋은 한국어 품질을 보였습니다. 자세한 비교는 `docs/model_comparison.md`에 정리되어 있습니다.

**Q: API 키 보안은 어떻게 처리하나요?**  
A: Fernet 대칭키 암호화를 사용하여 SQLite에 저장합니다. 암호화 키는 환경 변수로 분리 관리됩니다.

**Q: 여러 서버에서 동시에 사용 가능한가요?**  
A: 네, 서버별로 독립적인 설정이 SQLite에 저장되므로 다중 서버 동시 운영이 가능합니다.
