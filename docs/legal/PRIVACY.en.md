# NEXA Privacy Policy

Version: 2.0.0 (2026-06-10)

The NEXA Operator values your privacy and complies with applicable laws including the Personal Information
Protection Act (Korea). This policy applies to the NEXA service (App, central-server, Discord bot).

## 1. No Conversation Storage

The service does not store the body of your questions or conversations on the server. Questions are forwarded
to a contributor's (Provider's) PC and **processed locally**; the content is not retained after processing.

## 2. Data Collected

| Category | Items | Purpose |
|---|---|---|
| Account ID | Discord user ID, guild (server) ID | Service delivery, routing, permission checks |
| License | License status, trial start date, payment transaction ID (Paddle) | License management, refunds |
| Usage aggregates | Request count, time, success (excluding content) | Quota management, fairness, statistics |
| Contribution | Provider contribution records | Pool operation, event eligibility |

※ Email and payment method information at checkout is collected and stored by the payment processor **Paddle**;
the Operator does not store it directly.

## 3. Cross-border Transfer and Third Parties

| Recipient | Country | Items | Timing |
|---|---|---|---|
| Google (Gemini API) | USA | **Prompt content** when using cloud models | When using `/free-ask` etc. on a server where the admin enabled BYOK cloud |
| Paddle | UK/USA etc. | Email, payment info | On license purchase/refund |

When using cloud models (BYOK Gemini), that request's prompt is sent to Google. This occurs only on servers
where the server admin explicitly registered a cloud key.

## 4. Retention and Disposal

1. License/payment information is retained for the period required by applicable law (e-commerce law, etc.), then disposed of.
2. Usage aggregates are retained only as long as needed for statistics/quota management.
3. Upon account disconnection/withdrawal, related identifying information is disposed of without delay unless legally required to be retained.

## 5. Your Rights

You may request access, correction, deletion, and suspension of processing of your personal information via the contact below.

## 6. Age Restriction

The service does not collect personal information of those **under 14**, who may not use the service.
