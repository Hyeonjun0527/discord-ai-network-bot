## 2. 제공자별 특성 요약

### 2.1 Ollama (로컬 실행)

| 항목 | 내용 |
|------|------|
| 데이터 프라이버시 | 완전한 오프라인 처리 (데이터 외부 전송 없음) |
| 비용 | 무료 (하드웨어 전기 비용 제외) |
| 초기 설정 | Ollama 설치 및 모델 다운로드 필요 (`ollama pull <model>`) |
| 한국어 지원 | 모델에 따라 편차 큼 (llama3.2, gemma2 권장) |
| 권장 최소 RAM | 7B 모델: 8 GB / 11B 모델: 16 GB |
| 네트워크 | 불필요 (인터넷 연결 없이 동작) |

**Ollama 모델 설치 명령어**:
```bash
ollama pull llama3.2          # 3B 기본 모델
ollama pull llama3.2:11b      # 11B 고품질 모델
ollama pull mistral           # Mistral 7B
ollama pull dolphin-mistral   # Dolphin-Mistral 7B
ollama pull gemma2            # Google Gemma2 9B
ollama pull phi3:mini         # Microsoft Phi-3 Mini
```

### 한국어 적합성 등급

| 등급 | 모델 | 설명 |

## 5. 종합 권장 사항

1. **졸업 프로젝트 데모용**: `claude-sonnet-4-6` 또는 `gpt-4o-mini`  
   → 한국어 품질 최우선, 신뢰성 높은 클라우드 API

2. **프라이버시 중시 환경**: `llama3.2:11b`  
   → 데이터가 외부로 나가지 않으면서도 합리적인 한국어 품질

3. **API 키 없는 초기 테스트**: `llama3.2:3b`  
   → 설치 즉시 사용 가능, 기본 기능 검증용

4. **프로덕션 다중 서버 운영**: `gpt-4o-mini` + Fallback `llama3.2:11b`  
   → 비용 효율과 오프라인 폴백을 동시에 확보
