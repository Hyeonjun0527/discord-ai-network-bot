# NEXA engagement 조작 방지 보상 원칙 (reward safety)

- 작업: NEXA-P17-T018 (`human_gate: true`, security) · 상위: [ADR 0007](../../adr/0007-nexa-social-member-context.md)
- 근거: [threat-model.md](./threat-model.md), [banter-safety.md](../../../specs/product-v2/nexa/banter-safety.md),
  [disclosure.md](../../../specs/product-v2/nexa/disclosure.md)

NEXA 의 정책 모델·향후 RL 실험이 **대화량·멘션 수·체류만 최적화해 도발·의존·갈등을 유도하지 못하도록**
reward 설계의 금지사항과 검토 게이트를 정의한다. (제품 결정: XP/리더보드 같은 engagement 게임화는 폐기됨 —
이 원칙은 그 결정과 일관된다.)

## 1. 금지된 reward (anti-goals)

다음을 보상 신호로 삼는 것을 **금지**한다(단독 최적화 시 해로움):

| 금지 신호 | 왜 해로운가 |
| --- | --- |
| 총 대화량·메시지 수 최대화 | 도배·끼어들기·과다 발화 유도(점유율 cap 우회 압력) |
| 멘션·답장 수 최대화 | 도발·논쟁 유발로 상호작용을 늘리는 적대적 패턴 |
| 체류 시간·세션 길이 | 의존·중독 설계(다크 패턴) |
| 갈등·논쟁 발생률 | engagement-bait — 분란을 일부러 키움 |
| 부정 감정 유발 반응 | 어그로로 반응을 끌어내는 패턴 |

## 2. 허용되는 reward 방향 (다목적·안전 포함)

reward 는 **단일 engagement 지표가 아니라** 다음을 함께 포함하는 다목적이어야 한다:

- **적절성**: 끼어들지/물러설지 판단 정확도(침묵이 옳을 때 침묵).
- **사용자 만족·동의 존중**: opt-out·중단 신호·동의 경계 준수.
- **안전 위반 0**: 괴롭힘·고위험 오응답·정체 사칭·비밀 노출이 음(-)의 큰 페널티.
- **점유율 절제**: 과점(share cap) 회피가 보상에 포함.

## 3. 검토 게이트 (acceptance)

**향후 모든 RL/보상 실험의 reward 함수는 다목적 안전 검토를 통과해야 한다**(T018 acceptance). 검토는 다음을
확인한다:

1. reward 가 §1 의 금지 신호를 단독·주요 항으로 포함하지 않는다.
2. 안전 위반(괴롭힘·고위험·사칭·누출)에 충분히 큰 음의 페널티가 있다.
3. 침묵/물러섬이 정당할 때 그것이 페널티가 아니라 보상이다(과다 발화 압력 제거).
4. opt-out·중단 신호·동의 경계가 reward 에 반영된다.
5. 점유율 cap·비용 cap 과 충돌하지 않는다.

검토 책임자: 제품 안전 담당 + 보안 담당(P17-T025 승인 게이트와 연결). 통과 못한 reward 는 실험에 쓰지 않는다.

## 4. 비범위

- 구체적 RL 알고리즘·하이퍼파라미터는 이 문서 범위가 아니다(원칙·금지·게이트만).
- 런타임 안전 강제(괴롭힘 override·고위험 fallback)는 [banter-safety.md]·T016 이 코드로 담당한다 — 이 문서는
  **학습 신호 설계**의 안전을 다룬다.
