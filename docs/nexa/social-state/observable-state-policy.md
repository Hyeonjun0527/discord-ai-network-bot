# 사회 상태의 관찰 가능성 원칙

- 작업: NEXA-P06-T001 (`human_gate: true`, 윤리) · 상위: [ADR 0007](../../adr/0007-nexa-social-member-context.md),
  [ADR 0010 ainetwork·socialmemory 경계](../../adr/0010-ainetwork-socialmemory-boundary.md)
- 근거: [socialmemory-context.md](../architecture/socialmemory-context.md),
  [social-model-overlap.md](../baseline/social-model-overlap.md),
  [data-categories.md](../../../specs/product-v2/nexa/data-categories.md)

## 목적

NEXA의 사회 상태(socialmemory)는 **사람을 프로파일링하지 않는다.** 관찰 가능한 *행동 신호*만
기록하고, 내면·정체성에 대한 민감 추론은 금지한다. 이 문서는 P06 전체의 윤리 가드레일이며 모든
사회 상태 feature가 통과해야 하는 기준이다.

## 허용 — 관찰 가능한 행동 신호 (OK)

직접 관찰된 상호작용 사실에서 도출되며, 본인이 한 행동의 집계다:

- 응답률·응답 여부(니아에게 답했는가)
- 상호작용 빈도·최근성(언제 마지막으로 대화했는가)
- 메시지 간격·대화 템포
- 상호성(reciprocity — 주고받음의 균형)
- 관찰된 banter 수용(농담에 농담으로 반응했는가 — 행동, 추론 아님)
- 응답 기대(질문/멘션 후 답을 기다리는 정황)
- topic 참여(특정 주제 대화에 참여한 빈도)
- 미해결 상호작용(답을 약속했으나 아직 안 함 등)

## 금지 — 민감 추론 (NEVER)

행동에서 내면·정체성을 *추론*하는 것은 금지한다. 다음을 feature로 만들지 않는다:

- 기분·감정 상태 추론("이 사람은 화났다/우울하다")
- 성격 유형(MBTI, Big5 등) 추론
- 정치 성향·종교·세계관
- 성적 지향·성별 정체성
- 건강·정신건강 상태
- 인종·국적·인구통계 추론
- 호감/적대 같은 관계 *감정*의 단정(관찰된 상호작용 빈도는 OK, "이 사람은 나를 싫어한다" 추론은 금지)

## 코드 리뷰 체크리스트 (모든 사회 상태 feature)

1. [ ] 이 feature는 **본인이 한 관찰 가능한 행동**의 집계인가? (내면 추론이 아닌가)
2. [ ] 금지 목록(기분·성격·정치·종교·성적지향·건강·인구통계)에 해당하지 않는가?
3. [ ] 원문 메시지 내용을 저장하지 않고 신호/카운트/시각만 남기는가? ([data-categories.md](../../../specs/product-v2/nexa/data-categories.md))
4. [ ] guild 스코프이며 cross-guild로 사람을 식별·연결하지 않는가? (가명화, ADR 0010)
5. [ ] 옵트아웃 사용자는 제외되는가?
6. [ ] 시간 유효성(감쇠/TTL)이 있어 영구 낙인이 되지 않는가?
7. [ ] 관리자에게 설명 가능한가(왜 이 값인지 관찰 사실로 환원되는가)?

## acceptance 충족

- 허용/금지 feature **예시**(위 두 절)와 **코드 리뷰 체크리스트**(7항목)를 제공한다.
- 이후 P06-T005~T015의 모든 지표는 이 체크리스트를 통과해야 하며, 통과하지 못하는 추론 feature는
  구현하지 않는다.

## 불변식

1. 사회 상태는 관찰된 행동 신호의 집계이지 내면·정체성 추론이 아니다.
2. 금지 목록의 어떤 것도 feature·라벨·점수로 만들지 않는다.
3. 모든 사회 상태는 관찰 사실로 환원·설명 가능하고, 시간이 지나면 감쇠한다(영구 낙인 금지).
