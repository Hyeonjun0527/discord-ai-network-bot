# 응답 품질 평가 가이드

## 평가 기준

| 기준 | 설명 | 배점 |
|------|------|------|
| 정확성 | 채널 대화 내용을 올바르게 반영하는가 | 0~3 |
| 간결성 | 불필요한 반복 없이 핵심만 전달하는가 | 0~2 |
| 근거 인용 | 답변의 근거가 대화 내용에서 명확히 추적되는가 | 0~3 |
| 언어 일치 | 설정된 언어(ko/en 등)로 응답하는가 | 0~1 |
| 형식 적절성 | Discord에서 읽기 좋은 형식인가 | 0~1 |

총점: 10점 만점

1. "오늘 회의에서 결정된 사항이 뭐야?"

5. "이번 스프린트에서 해결해야 할 이슈가 뭐야?"
6. "팀에서 합의한 기술 스택은?"
7. "코드 리뷰 피드백 요약해줘"
8. "오늘 논의된 버그 원인은?"
9. "다음 릴리즈 기능 목록은?"
10. "팀 전체 채널에서 가장 많이 언급된 주제는?"

## 평가 방법

1. 동일한 Discord 채널에서 동일한 대화 내용을 준비한다.
2. 각 모델로 10개 질문을 순서대로 실행한다.
3. 위 기준에 따라 0~10점 척도로 점수를 기록한다.
4. 3회 반복 실행 후 평균을 낸다.
5. 응답 시간(latency_ms)도 함께 기록한다.
