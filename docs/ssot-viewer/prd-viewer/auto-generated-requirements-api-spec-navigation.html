Discord Assistant / NEXA

NEXA는 디스코드 서버에 AI 운영 레이어를 붙이는 서비스다

서버 관리자가 봇을 추가하고 채널별 AI 성격·지식·정책을 정한다. 멤버는 Discord에서 /질문로 질문하고, 로컬 Provider는 품질 주력이 아니라 저비용/배경/커뮤니티 용량이 필요할 때 보조한다.

1. 이 서비스는 무엇인가

NEXA의 핵심은 “로컬 AI가 최고 답변을 한다”가 아니다. 핵심은 디스코드 서버에 AI 운영 레이어를 붙여 채널 정책, 지식공간, 프리셋, 안전 제한, 품질 피드백을 관리하고, 로컬 AI는 낮은 위험의 보조 작업이나 커뮤니티 기여 용량이 필요할 때만 활용하는 것이다.

디스코드 서버 운영자가 채널별 AI 도우미를 붙이고, 중앙 서버가 정책·지식·프리셋·라우팅을 관리하며, 로컬 Provider는 품질 주력이 아니라 저비용/배경/커뮤니티 용량 티어로 보태는 시스템.

사용자가 체감하는 약속
  • 일반 유저는 Provider PC나 모델 서버를 몰라도 Discord /질문와 채널 AI로 질문한다.
  • 서버 관리자는 채널·역할·프리셋·지식공간·안전 리포트·Provider 승인 정책을 운영한다.
  • 중앙 서버는 정책, 지식 컨텍스트, 라우팅, 세션, 관측성, Discord 응답을 책임진다.
  • 로컬 Provider는 고품질 답변 보장이 아니라 저비용/배경/낮은 위험 작업을 보태는 선택적 용량 티어다.
  • Provider는 자기 PC 자원을 명시적으로 기여하며 언제든 중지할 수 있다.
이 서비스가 아닌 것
  • 로컬 LLM만으로 상용 frontier 모델 수준의 답변 품질을 보장하는 것
  • 판매자/구매자/가격표/수수료/정산/프로바이더 수익 모델
  • 여러 PC의 GPU/CPU를 합쳐 하나의 거대한 모델을 실행하는 분산 추론
  • Provider의 동의·한도·가용성을 우회하는 품질 향상
  • 사용자가 Provider PC에 직접 접속하거나 임의 파일/쉘/URL을 실행하는 기능

이 서비스가 아닌 것

로컬 AI 품질을 주력으로 파는 서비스가 아님

로컬 모델은 대부분 상용 frontier 모델보다 약하다. 그래서 NEXA는 로컬 AI 자체가 아니라 Discord 서버용 AI 운영, 정책, 지식, 프리셋, 품질 피드백을 제품 중심으로 둔다.

AI 판매 마켓이 아님

Provider는 판매자가 아니라 커뮤니티에 감당 가능한 만큼 기여하는 사람이다.

여러 PC를 합쳐 큰 모델을 돌리는 게 아님

성능을 합치는 분산 추론이 아니라, 가능한 Provider 중 안전하게 하나를 고르는 라우팅이다.

남의 PC에 직접 접속하는 앱이 아님

Agent는 outbound 연결만 쓰고, 중앙 서버 요청 외 임의 파일/쉘/URL 실행을 허용하지 않는다.

니아가 유료·별도 계정 캐릭터가 아님

니아는 NEXA의 기본 AI 정체성이다. 호감도는 관계 표현 장치일 뿐 XP·리더보드·과금이 아니고, 서버가 자기 채널 AI 페르소나를 만들면 그 성격으로 대체된다(안전 가드레일은 항상 우선).

유료 구독 서비스가 아님

기본 질문·채널 AI·Provider 풀 기여는 영구 무료다. 서버별 페르소나·RAG·프리셋 쓰기 같은 앱 관리 프리미엄만 3개월 체험 후 $10 영구 라이선스로 열린다(구독 아님, ADR 0005).
