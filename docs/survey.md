## 채점 기준 / Scoring Reference

| 항목 / Item | 문항 / Question | 척도 / Scale |
|---|---|---|
| 사용 편의성 (Ease of Use) | Q1, Q2 | Likert 1–5 |
| 기능 유용성 (Feature Usefulness) | Q3, Q4, Q5 | Likert 1–5 |
| 응답 품질 (Response Quality) | Q6, Q7 | Likert 1–5 |
| UI 편의성 (UI Convenience) | Q8 | Likert 1–5 |
| 추천 의향 (NPS) | Q9 | 0–10 |
| 전반적 만족도 (Overall Score) | 전체 평균 (Overall Average) | 1–5 환산 |

### NPS 계산 방법

- Promoters: 9–10점
- Passives: 7–8점
- Detractors: 0–6점
- **NPS = (Promoters % − Detractors %) × 100**

### 목표 기준 (Target Benchmarks)

| 지표 | 목표값 |
|---|---|
| 사용 편의성 평균 | ≥ 3.5 / 5 |
| 응답 품질 평균 | ≥ 3.5 / 5 |
| NPS | ≥ 0 (양수) |
| 추천 의향 | ≥ 7 / 10 |
