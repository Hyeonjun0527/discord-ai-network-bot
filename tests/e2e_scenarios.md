# E2E 테스트 시나리오

## 시나리오 1 — 신규 서버 설정 → 요약

**전제 조건:** 봇이 새로운 Discord 서버에 초대되어 있음.

**단계:**
1. `/settings` 실행 → 현재 기본값(llama3.1:8b, ko, 50개) 확인
2. 모델 관리 버튼 클릭 → 모델을 `qwen2.5:7b`로 변경
3. 언어 버튼 클릭 → `en`으로 변경
4. `/summarize` 실행 → 영문 요약 응답 확인

**기대 결과:**
- `/settings` 패널이 ephemeral 메시지로 표시됨
- 모델 변경 후 DB에 `qwen2.5:7b`가 저장됨
- `/summarize` 응답이 영어로 출력됨

---

## 시나리오 2 — API 키 등록 → OpenAI 전환 → /chat

**전제 조건:** 유효한 OpenAI API 키 보유.

**단계:**
1. `/settings` → 모델 관리 → `OpenAI`로 제공자 변경
2. API 키 등록 버튼 클릭 → `sk-...` 형식의 키 입력
3. `/chat message:파이썬으로 Hello World 코드 작성해줘` 실행

**기대 결과:**
- API 키가 암호화되어 DB에 저장됨
- `/chat` 응답이 OpenAI GPT 모델에서 옴
- 응답 내용이 한국어로 Hello World 코드를 설명함

---

## 시나리오 3 — /ask 질문 → 후속 질문

**전제 조건:** 채널에 최근 대화가 10개 이상 있음.

**단계:**
1. `/ask question:오늘 회의 결론이 뭐야?` 실행
2. 응답 확인 후 `/ask question:그 결론을 실행할 담당자는?` 실행

**기대 결과:**
- 첫 번째 질문에 채널 대화 기반 답변이 표시됨
- 두 번째 질문도 같은 채널 대화에서 근거를 찾아 답변함
- 채널 대화에 없는 내용은 "대화에서 찾을 수 없습니다" 형태로 답변함

---

## 시나리오 4 — 자동 요약 설정 (멘션 트리거)

**전제 조건:** 봇이 서버에 있고 `message_content` 인텐트가 활성화됨.

**단계:**
1. 채널에서 `@봇이름` 멘션 (질문 없이)
2. 채널에서 `@봇이름 어제 무슨 얘기 했어?` 멘션

**기대 결과:**
- 첫 번째 멘션: 최근 대화 요약이 채널에 공개적으로 게시됨
- 두 번째 멘션: `/ask`처럼 동작하여 질문에 답변함
- 응답 중 typing 인디케이터가 표시됨

---

## 시나리오 5 — 에러 케이스: Ollama 중단

**전제 조건:** Ollama가 실행 중인 상태에서 시작.

**단계:**
1. Ollama를 중단함 (`pkill ollama` 또는 서비스 종료)
2. `/summarize` 실행
3. Ollama를 재시작함
4. `/summarize` 재실행

**기대 결과:**
- Ollama 중단 시: "Ollama가 실행 중이지 않습니다. 터미널에서 `ollama serve`를 실행해 주세요." 에러 메시지가 ephemeral로 표시됨
- 재시도 로직이 2회 시도 후 에러를 반환함
- Ollama 재시작 후: 정상 요약 응답이 반환됨
